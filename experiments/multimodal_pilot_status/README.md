## 当前结论

- 六类共 160 条轨迹已建立多模态读取流程；最近一轮视觉实验使用新版遮挡类 `occlusion_v4_nearby`。
- 多模态 CSI 小实验只覆盖高速与遮挡。巡航、转弯、折返、爬升下降尚未完成多模态贡献对比。
- 高速类新增模块未超过冻结 CSI 骨干，最佳权重退回零修正初始化。
- 遮挡类尚未获得可靠的 RGB 增益；部分配置存在很小的运动状态收益。
- 真实未来 LoS 标签能改善遮挡 CSI 预测，但属于不可部署的诊断，不是视觉预测成果。
- 图像特征能部分区分当前 LoS/NLoS；本轮视觉时序 Transformer 未学到有效未来预测。尚无 UAV 可见率统计，不能断言图像中没有 UAV。
