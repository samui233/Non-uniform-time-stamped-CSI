# 单模态非均匀 CSI 预测实验协议

本目录负责训练和评估，不生成射线数据。模型的来源、原方法与本次矩阵 CSI 适配的区别见 `docs/MODEL_ADAPTATIONS.md`。

## 输入、归一化与公平比较

每个样本只有预测原点之前的不规则 CSI 观测，时间以秒表示，预测原点为零。历史数量可变，padding 由布尔 mask 标识；目标是给定正时间处的完整复数 CSI，而不是波束或仅幅度。

共同压缩采用**只用训练集拟合、无中心化的复数正交 PCA**。每个复数系数的实虚部交错组成网络特征。一个样本使用“已观察历史完整 CSI 的平均 Frobenius 能量的平方根”作为唯一归一化尺度；预测目标不参与尺度计算。预测后使用同一正交基恢复完整矩阵。重建丢失的正交补能量计入验证和测试误差，不能把压缩空间误差冒充完整 CSI 误差。

训练监督项与既定验证指标一致：每个目标的系数平方误差之和加正交补残差，除以该目标的完整真实能量，再对所有目标等权平均，即逐目标完整矩阵 NMSE。正交补残差与模型参数无关，只用于让日志保留完整矩阵含义。真实目标能量仅用于监督损失权重，不输入模型，不修改历史尺度或推理时反归一化；不夹紧有效非零目标能量，也不截断单个样本损失。Latent ODE、Neural Flow 的变分辅助项按模型文档说明采用小权重 KL，5 个 epoch 线性预热；日志中的总loss因此还可能包含这项辅助损失。这属于明确记录的监督 CSI 适配，不声称完整复现原文所有概率目标。

正式测试前的 TRAIN-only 审计发现，旧的“仅历史能量归一化MSE”几乎全部被少数弱到强恢复目标支配，因此旧目标试跑不用于最终方法比较。证据、原始逐目标值和重现脚本见 `results/training_objective_audit` 与 `audit_training_objective.py`。改用NMSE是对齐预先确定的验证目标，不保证强到弱深衰落的相对误差尾部自动消失。新目标从头训练，不继承旧目标优化器；checkpoint记录 `loss_name` 和 `engine_sha256`，恢复时拒绝目标或引擎版本不一致。

保持、因果线性拟合、连续时间恒速卡尔曼滤波直接使用**完整历史矩阵**，不受 PCA 下限约束。卡尔曼在真实时间间隔下传播位置—速度状态；连续白加速度过程噪声与观测噪声的比值只在验证集选取，后续鲁棒性实验复用该数值。

另加入**谐波最小二乘（Harmonic LS）**作为经典相位外推对照，不列入Time-IMM神经方法。它仅利用完整复数历史与实际时间，拟合一个共享有符号频率和逐CSI元素的复数常量/谐波权重，然后在查询时间计算外推值。默认在密集数据频率的正负二分之一范围内搜索，粗网格1 Hz、细化0.1 Hz；参数固定，不做验证/测试调优。该频带是数据采样时钟给出的先验，不是稀疏非均匀历史的普遍Nyquist保证；单频模型也不代表所有多径都共享真实物理频率。主测试、真实off-grid和16个受控历史条件均包含它，时间戳消融与均匀重训仍针对神经模型。

## 射线标签可用性与覆盖范围

有限预算的射线搜索没有找到路径时，不能据此认定物理信道严格为零；零能量目标的 NMSE 本身也没有定义。因此原始射线结果全部保留，但主实验明确限定为**可解析链路上的 CSI 条件预测**。

在抽取训练/评估窗口前执行 `prepare_windows.py`。一个截止点合格，当且仅当历史 400 ms 至未来 500 ms 的全部密集帧都具有正路径数、有限且严格为正的完整信道能量。真实 off-grid 实验进一步要求该截止点的四个实际查询目标全部具有有限正能量。该规则不使用增益下限、跳变大小、预测误差或测试分数；弱但可解析的深衰落仍保留。

这是离线标签可用性筛选，**不是可在推理时观察未来的在线门控**。未来可用性标记不输入模型，不参与历史归一化，也不用于推理时选择预测长度。结论不外推到未找到路径的区域或断链事件预测。

每条轨迹的 `eligible_cutoffs.npy`、`eligible_offgrid.npy` 固定所有模型及历史数量/时间模式使用的候选窗口；`window_coverage.json` 记录各轨迹与数据划分的原始数量、排除数量及覆盖率。加载器缺少这些文件会直接报错，不会静默使用全部窗口。历史尺度仅按实际观测计算，不引入训练集平均增益替换弱信道；异常或数值不可解析尺度会报错而非偷偷限幅。checkpoint 与评估同时校验覆盖报告和加载器源码指纹，防止窗口定义变化后复用旧实验。

## 训练和选择

- 四个方法分别用随机种子 17、29、43 训练。
- 默认最多 40 epoch，每 epoch 12,000 个新采样窗口；验证窗口固定。
- AdamW，初始学习率 3e-4，余弦衰减，梯度裁剪 1，连续 6 epoch 无有效验证改善时停止。
- 依据验证集“逐目标 NMSE 先在线性域平均”的值选择 `best.pt`；不依据测试集选模型、epoch 或噪声参数。
- `latest.pt` 包含网络、优化器、学习率调度器、随机状态、epoch 和累计时间，支持恢复。`history.csv` 记录简洁训练信息。
- GPU 使用 TF32/BF16；CRU 的原始核心保留双精度。各模型采用实测安全批量大小，以提升吞吐，优化器及其它训练协议相同。

## 主评估

未来时间为 10、20、50、100、200、500 ms。主要指标是**完整矩阵逐目标 NMSE 在线性域平均后转 dB**。另保存物理能量加权 NMSE、幅度 NMSE、复数形状相关、功率增益绝对误差，避免单个总数掩盖模型预测了什么。

逐目标原始文件保留轨迹、场景、预测原点、预测时间、历史数量、历史模式、LoS/NLoS 及是否跨越状态切换。按完整轨迹聚类 bootstrap，而不是把相邻窗口当成独立样本。每个模型同时给出与保持法的配对轨迹 bootstrap 差值区间。不同训练种子不是额外的数据轨迹，不用于虚增样本数。

## 不规则时间实验

1. **等观测预算**：历史数量 4、8、16、32，分别使用 uniform、random、bursty、dropout 模式。相同样本标识的预测原点和目标保持一致。
2. **时间戳是否被利用**：保持输入观测及目标，分别用均匀时间标签、打乱观测—时间对应、5 ms 和 20 ms 时间误差测试模型。误差后的时间仍限制在预测原点之前。打乱对应是强破坏性消融，不等同于普通传感器抖动。
3. **训练分布**：只根据验证集跨种子平均结果选定一个模型，另在均匀历史上从头训练；再在四种模式上与混合历史训练比较。不是从测试结果选择最有利模型。
4. **物理场景分层**：主结果按轨迹类型和 LoS 切换状态汇总，观察高速机动、转弯、遮挡条件是否改变可预测性。

`uniform` 是在固定0.4秒端点之间等分后，取最近的500 Hz密集真值栅格。因此当200个栅格间隔不能被历史数量减一整除时，它是**栅格量化的近均匀采样**，相邻间隔最多相差一个2 ms栅格，不是理想的严格等间隔时钟。所有方法都接收实际取样时间。这种细微差别在无噪声高频信号的频率辨识中也可能有影响，不能将该对照直接解释成严格均匀采样的Nyquist极限实验。

主评估目标来自密集射线仿真的离散时间网格。此外，每条验证/测试轨迹另选 24 个历史截止点，每点随机选择 4 个非网格未来时刻，并在这些时刻重新执行射线追踪。`--offgrid` 使用这些真实目标，不做 CSI 插值；完整的实际查询时间保存在逐目标结果中，并按提前量区间汇总。它检验的范围仍限于训练约定的未来区间，不代表任意远期外推。

为限制总体运行时间，主要预测实验使用三个训练种子；16 种历史模式/数量组合及时间戳消融预先固定种子 17，不通过验证或测试分数挑选种子。均匀训练对照同样使用种子 17。时间消融有独立的同种子原始时间戳参考，不能拿单个种子的扰动结果与三个种子的平均值作严格配对。

## 一条命令

```bash
/root/miniconda3/envs/SimART/bin/python run_experiments.py \
  --data-root DATASET_DIRECTORY \
  --basis PCA_BASIS.npy \
  --output EXPERIMENT_DIRECTORY
```

可用 `--stage train/evaluate/stress` 分阶段继续。训练默认恢复已有 latest，评估跳过已完整写出 summary 的结果目录。修改数据或协议后应使用新的输出目录，避免复用旧结果。绘图直接读取结果 JSON，保留 `plot_values.csv` 和跨条件 `all_conditions.csv`。
