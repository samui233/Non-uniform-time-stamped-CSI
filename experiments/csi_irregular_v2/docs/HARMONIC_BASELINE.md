# 不规则历史的单频复数最小二乘对照

`benchmark.harmonic.HarmonicLS` 是简单的信号模型对照，不属于 Time-IMM 方法，也不是新训练网络。

它假设每个 CSI 元素由复数常量与一个复数旋转项组成，所有元素共享同一个有符号频率，但各自具有不同的复系数。拟合只使用实际历史 CSI、历史时间戳和有效观测掩码；查询时间仅在最后计算预测时使用，不影响估计的频率。没有读取目标、未来统计或轨迹标识。

候选频率范围由 `sampling_hz/2` 决定，默认500Hz原始采样率对应−250到250Hz；可以显式缩窄，但不能超过配置的范围。该范围是一项带限先验，不意味着任意不规则采样都具有简单的同一奈奎斯特界。先用1Hz网格搜索，再在最佳候选附近用0.1Hz细化。粗网格和细化步长均是显式构造参数。

计算时先按实际观测的平均时间居中，复数旋转基函数再减去其历史均值，使常量项与旋转项正交。零频率及在给定历史上恰好退化为常量的候选不参与除法；常量CSI直接返回历史均值。候选得分由 `[L,L]` 的历史 Gram 矩阵计算，不构造 `[候选频率,完整CSI元素]` 的巨大拟合张量。只对选出的频率计算完整各元素系数。

接口与其他 baseline 一样是 `forward(x,times,mask,query)`。既支持完整复数 `[B,L,8192]`，也支持现有评价器使用的实虚交错 `[B,L,16384]`；返回对应的数据类型与特征排布。没有使用公共 PCA，避免把压缩误差加入这个简单对照。

主要限制：

- 它只拟合一个近似恒定频率，不能完整表达多个具有不同多普勒变化的传播分量。
- 加减速、路径突现消失和幅度快速改变会打破假设。
- 少量、不规则或成簇的历史仍可能混叠。多个频率能够解释同一段历史时，未来不一定可辨识；本方法不声称解决不可辨识性。
- 在有限、含噪历史上选择频率可能过拟合；单频失配时，历史残差较小也不保证长时预测准确。
- 本实现只有最佳粗网格候选的局部细化，既不是连续频率全局优化，也不利用未来误差挑候选。

`tests/test_harmonic.py` 检查已知正/负频率、不规则时间、DC、噪声和双频失配，并检查 padding、成对排列、查询集合与实虚接口的一致性。合成正确性测试不能代替真实 CSI 的泛化实验。该方法已集成到主基线工厂、完整测试及绘图，正式结果使用下述数值修复后的版本。

## 时间精度与可辨识性修复

后续评估发现一个数值实现缺陷：若历史时间恰好是某候选周期的整数倍，该候选本应与常量项完全重合。float32 时间的微小舍入误差却可能产生一个非零的中心化旋转基函数；仅用内部 float64 的 epsilon 判定可辨识性，会错误地拟合这种舍入误差，并产生巨大且相互抵消的常量/旋转系数。

现实现保留输入时间的数据类型，用相邻可表示数的最大间距 ULP 给出各时间的保守舍入误差上界。候选旋转项的范数平方必须大于原浮点运算容差加上 `sum((2*pi*f*ULP(t))**2)` 才参与拟合。该项来自复指数的相位扰动上界与中心化投影不增加范数的性质；没有按验证或测试得分搜索阈值，也没有对时间取整、对预测截幅或对真实变化做平滑。查询时间不参与此判定。

CPU 回归测试加入了独立构造的4ms规则格点、float32/float64精度差异以及可分辨的真实时间微扰；数值别名会被排除，真实非均匀时间仍直接使用。旧实现与独立 NumPy complex128 最小二乘的诊断保存在 `results/harmonic_numerical_audit/`。这项修复只排除由表示精度造成的假可辨识性，不能消除真实多频混叠、深衰落或单频模型失配。
