# 单模态 CSI 预测模型实现说明

这些模型是原论文方法在 CSI 预测任务上的适配，不能把本实验结果称为原论文数据集分数的复现。源码版本、论文和许可见同目录的来源审计文档及 `third_party/`。尤其 CRU 的原始核心保留 AGPL-3.0-or-later 许可，不能因为外围工程采用其他许可而覆盖它。

## 统一接口

`models.create_model(name, input_dim, **kwargs)` 接收以下四个张量：

- `x[B,L,F]`：历史 CSI 的实数特征，当前计划为训练集拟合的复数线性子空间系数，其实部/虚部交错排列。子空间维度由数据模块评估重建误差后确定。
- `times[B,L]`：相对预测截止点的真实秒数，非正数；有效历史按时间递增。
- `mask[B,L]`：哪些时刻实际被观测，至少一个有效点。无效槽内的值与时间会被屏蔽。
- `query[B,Q]`：相对相同截止点的未来查询秒数，正数。

输出为 `prediction[B,Q,F]`，再由同一个固定线性变换重建复数 CSI 矩阵。模型不知道查询点的真实 CSI，也不读取未来的位置或速度。历史归一化只允许使用已观测历史，不能使用未来能量。最终评价须包含子空间重建误差，而不只评价低维系数。

各个样本可以使用不同历史数量、不同历史时间以及不同查询时间。每个查询从同一历史后验独立计算，因此增删其他查询点不应改变该查询预测。没有用等间隔插值替代模型内的真实时间。

## CRU

工厂名：`cru`。直接加载 Bosch 原始 `lib/CRUCell.py`，不是普通 GRU 或指数衰减 RNN。

CSI 系数经两层 tanh MLP 输出高斯潜观测的均值和方差，均值使用原始编码器的 L2 归一化，方差使用平方激活并加极小正数。连续潜状态维度默认 32，观测部分为 16，另 16 维为隐藏部分。状态相关的八个局部线性基矩阵构成连续动态矩阵；原始矩阵指数和 Van Loan 方法计算任意真实时间间隔后的均值及过程噪声协方差。每次历史观测使用原始结构化 Kalman 更新，维持上块、下块和交叉块的对角协方差。未来查询从最后观测后验分别传播。

核心维持原始 float64 以避免矩阵指数/协方差数值检查失真，前后端 MLP 为 float32。保留带状动态矩阵与状态相关混合系数；未替换为离散时间 RKN，也未启用不同公式的 f-CRU。CSI 输出为均值回归，因此没有复制原论文的异方差输出似然损失；模型仍通过潜高斯不确定性控制观测融合。

## Latent ODE

工厂名：`latent_ode`。根据 Rubanova 原始 `encoder_decoder.py` 中 ODE-RNN recognition 和 GRU_unit 方程实现批量适配。

从最近历史点逆序遍历至最早历史点：隐均值在相邻真实时刻之间按 ODE 演化，观测经带重置门、更新门的原始均值/标准差 GRU 更新，然后得到最早历史时刻的高斯潜初态。训练时重参数化采样，评价时使用后验均值，消除单次随机潜变量采样导致的评价抖动。独立生成 ODE 将该初态从**最早真实历史时刻**推进至各未来查询，再通过下文统一的 CSI 矩阵解码头输出系数。

数值求解改为可批量处理不同时间间隔的四阶 RK4：默认 recognition 每段 2 子步、generation 每查询 24 子步；这不是原始自适应 dopri5 的逐字复刻，须另做步数加倍的数值收敛检查。保留连续微分动态、反向 ODE-RNN 和变分潜初态三项定义机制。去除了 Poisson 观测过程和分类支路，因为当前任务不是这些任务。

## Neural Flow

工厂名：`neural_flow`。直接加载 Bilos 官方 `nfe/models/flow.py` 中的 CouplingFlow，并使用该仓库指定的 `stribor==0.1.0`；当前新版 stribor 接口不同，不能随意替换。

原始连续仿射 coupling layers 交替分割潜变量，使用 `TimeLinear` 保证零间隔是恒等变换。默认两层 coupling、两层隐藏 MLP。recognition 使用官方 latent-ODE 实验的反向 flow + LSTMCell，而不是借用 Latent ODE 的 GRU。由最早历史点后验生成初态，连续生成 flow 按查询相对该初态的真实时间直接求解，不用 ODE 数值求解器。训练采样、评价后验均值与 Latent ODE 相同。

## t-PatchGNN

工厂名：`tpatchgnn`。直接加载原作者 `tPatchGNN/model/tPatchGNN.py` 的全部模型类。加载时只移除该文件实际未使用的工程级导入，并将构造时写死的 `.cuda()` 去掉以支持正常 `.to(device)`；TTCN、Transformer、图卷积和解码方程均保留。

历史物理时间范围默认 0.4 秒，划分为四个不重叠时间 patch。每个原始观测分配到其真实时间所在 patch，而不是插值成规则序列。各特征通道中，TTCN 根据观测值与可学习时间嵌入生成归一化滤波权重，聚合 patch 内任意数量观测；时间 Transformer 建模 patch 演化；门控节点嵌入产生每个 patch 的动态有向图，再进行二阶图卷积。聚合历史 patch 后，将未来查询时间嵌入与每通道状态结合，逐通道解码未来 CSI 系数。

默认隐藏维 32、一组 Transformer/图卷积层、四头注意力、四个 patch；这些是规模配置，不是删除定义模块。图节点是线性子空间实数系数，不直接等同于物理天线，其关系需要模型学习。图复杂度随 F 的平方增长，所以不能直接把 16,384 个实虚 CSI 元素作为图节点。

## 训练目标与边界

正式训练前统一调整了 CRU、Latent ODE、Neural Flow 的 CSI 输出头，使用 `Linear(latent_dim, max(128,F)) → Tanh → Linear(max(128,F),F)`。连续状态维仍为 32，原始状态演化与识别核心未改变。这是明确的 **CSI 高维矩阵解码器适配**，不再称为原论文线性 decoder 的逐字复现。t-PatchGNN 保留原始逐特征头，其整体输出没有同一种固定 32 维仿射子空间约束。

原因不是测试集调参：正式训练和测试前，在已完成训练数据上发现，单个 `Linear(32,F)` 强制所有输出落在固定 32 维仿射子空间。25 条训练轨迹的 1,600 个抽样帧上，该约束的理想重建平均误差仍约 −12.12 dB，95% 分位约 −5.45 dB，会混淆“时间建模失败”和“输出无法表达”。统一宽非线性头移除了这项额外固定线性秩限制；公共复数 PCA 仍是所有模型共享且明确审计的线性压缩。诊断使用训练数据，未按测试性能选择架构。

Time-IMM 公布的 forecasting wrapper 使用预测 MSE，没有将 Latent ODE/Neural Flow 返回的 KL 加入统一训练损失；其 `n_traj_samples=1` 注释也不意味着预测确定性。这里不照搬该注释。

所有模型以同一逐目标完整矩阵 NMSE 监督项训练，具体定义见 `benchmark/实验协议.md`。两个变分模型另暴露 `model.aux_loss`，为相对标准正态先验的逐潜维平均 KL，采用 `1e-4` 权重并在前5个epoch线性预热，权重保存在运行配置中。这应称为**面向 CSI 点预测的 beta-VAE 适配目标**，不是原论文全部历史重建项与 IWAE 估计器的精确 ELBO 复现，也不声称与 Time-IMM 的原始 MSE 训练器完全相同。

默认网络直接预测 CSI 系数，不在输出端自动加最近一次 CSI。共享线性压缩、历史能量尺度与所有超参数必须写入 checkpoint 配置；压缩质量不好时，应增加子空间维度，而不是通过只汇报系数误差掩盖矩阵误差。

## 实现检查

运行 `python tests/test_models.py cuda`（也可 `cpu`）。检查四种模型的输出形状、有限值、可反向传播、无效 padding 值/时间不影响输出、额外 padding 不改变输出，以及单独查询与批量查询的同一时刻预测一致。它们是实现检查，不代替测试集性能与多随机种子实验。
