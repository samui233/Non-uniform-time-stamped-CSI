# 使用保存的模型查询任意未来时刻

`predict.py` 接受用户提供的 CSI 历史，不依赖该历史来自数据集中某条固定轨迹。当前默认训练支持 4–32 个历史观测，回看范围为 0.4 秒，未来查询范围为 `(0,0.5]` 秒。这些范围由匹配 checkpoint 的数据配置决定；历史数量优先读取 `history_count_min`/`history_count_max`，否则取 `history_counts` 的最小/最大值，与训练加载器一致，不在预测代码中写死。区间内查询可以不在 500 Hz 栅格上，例如 0.0137 秒；程序不把查询四舍五入到栅格点。

## 输入格式与运行

输入为一个 NPZ 文件，包含：

- `H`：complex64/complex128 数组 `[L,64,128]`，真实物理幅度的复数 CSI。
- `time_s`：float64 数组 `[L]`，每个历史矩阵对应的秒时间戳。可用相对秒数或绝对时间，但截止点必须采用同一个时钟。

例如，从一条原始轨迹选取非均匀历史：

```python
import numpy as np
route = "/root/autodl-tmp/csi-irregular-benchmark/data/routes/cruise_000"
h = np.load(route + "/H.npy", mmap_mode="r")
t = np.load(route + "/time_s.npy")
ix = np.array([1000, 1011, 1040, 1105, 1151, 1187, 1200])
np.savez("history_input.npz", H=h[ix], time_s=t[ix])
```

随后运行（正式模型现已训练完成）：

```bash
cd /root/autodl-tmp/csi-irregular-benchmark
/root/miniconda3/envs/SimART/bin/python predict.py \
  --history history_input.npz \
  --checkpoint runs/main_v1/checkpoints/latent_ode_seed17/best.pt \
  --basis data/compression/basis.npy \
  --query-offsets-s 0.0137 0.05 0.173 0.5 \
  --output prediction.npz
```

默认截止点是最后一个历史时间戳。也可显式设置 `--cutoff-s`。程序排序历史，但拒绝重复时间戳、截止点之后的观测、超过回看范围的历史以及超出训练范围的数量和查询偏移。不会静默裁掉历史、重采样或替用户改变截止点。若历史短于完整回看范围、或最新观测早于截止点，会明确提示它与训练时的端点固定协议不同；可以计算，但不能把这种外推输入条件的性能等同于已验证条件。

工程还保存了实际运行的示例 `examples/irregular_query/history_input.npz` 与 `prediction.npz`：7个不等间隔历史点，查询偏移13.7、50、173、500 ms，使用正式CRU seed17 checkpoint。来源索引与选择规则见同目录 `source.json`，不含未来CSI输入。可用 `export_prediction_example.py` 查看如何从正式测试轨迹构造这个输入；脚本不会覆盖已有示例。

输入 CSI 必须使用与训练相同的天线/子载波布局、频率定义和相位参考，以对应数据配置中的 `csi_reference` 为准。V1 使用逐链路最早路径参考；V2 使用收发位置直线距离定义的几何时延参考，即便没有 LoS，也不把这段直线假称为存在的传播路径。任意真实采集设备的 CSI 不能只因形状相同便认为可直接泛化。

## 输出与安全校验

输出 NPZ 包含：

- `H[Q,64,128]`：已重建并恢复历史物理幅度尺度的复数预测，仍保持该模型训练时的时延/相位参考。
- `time_s[Q]`：截止点加查询偏移，保留查询输入顺序。
- `query_offsets_s[Q]`：实际查询偏移，没有栅格取整。
- `metadata_json`：模型与 checkpoint 身份、基底/代码哈希、截止点、历史时间、归一化尺度以及输入支持范围提示。

归一化只有一个标量：提供的全部历史 CSI 的平均 Frobenius 能量开方。非有限值、全零或归一化尺度不大于 `1e-15` 的历史会按训练加载器的规则拒绝，不静默截断尺度。没有读取未来统计量。恢复这个幅度尺度**不等于恢复绝对传播相位**；V2 输出仍然是几何参考的 H。若要转回绝对传播相位，还需要未来查询时刻的几何时延，当前单模态预测接口既不读取也不猜测这个未来量。模型在评价模式使用确定性后验均值；GPU前向与正式评价一样使用 BF16 autocast，CRU 原始核心仍为 float64。

程序要求 checkpoint 的基底、模型代码、数据加载/归一化代码和数据配置哈希匹配。训练配置默认从基底所在数据目录读取；迁移目录后可通过 `--data-config` 显式提供同一文件。不会要求外部历史出现在训练 manifest 中。只加载信任的 checkpoint，因为训练格式包含 Python 对象。已有输出不会被覆盖。

## ODE 求解器检查

训练完成后可运行：

```bash
/root/miniconda3/envs/SimART/bin/python check_solver_convergence.py
```

默认读取 seed17 的 Latent ODE 最优 checkpoint，在固定 64 个验证窗口上比较 RK4 的默认 generation/recognition 子步数和各自加倍后的预测。两者都显式解码为完整复数 CSI；结果保存到 `results/solver_convergence/`。数值检查关闭 AMP 与 TF32，以区分积分步长影响和混合精度舍入，不使用测试集调参。
