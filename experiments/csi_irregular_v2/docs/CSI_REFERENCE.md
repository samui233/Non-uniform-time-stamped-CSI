# CSI相位与时延参考

本文区分已归档的 V1 最早路径参考与当前正式采用的 V2 几何直线参考。V2已通过同一路径解的代数等价、幅度保持与局部连续性验证，正式120条轨迹重生成已启动；是否全部完成以 `data/routes/*/complete.json` 为准。该变更独立于1毫米镜面共面判定修复，后者仍按原配置使用。不据局部验证宣称所有轨迹已经可预测。

## V1为什么仍有快速变化

V1调用当前 Sionna-RT 2.0.1 的 `Paths.cfr(normalize_delays=True)`。安装源码 `paths.py::cir` 先对有效路径取最小时延并减去它，随后计算载频相位；`cfr` 再用相同相对时延计算子载波频率相位。因此，移除的不是第一根天线相位，而是每个收发链路当前最早有效路径的公共传播时延。

这个参考依赖有效路径集合：较弱但更早到达的路径出现或消失，也会改变其余强路径的参考。V1验证轨迹 `occlusion_018` 中，幅度近乎稳定却出现单路径零相对时延与多路径约350 ns有效时延的反复切换。此时仅去除每帧公共相位还不够，频率线性相位也随参考变化。初步只读证据见 `results/sampling_audit_candidate_v1/weak_nlos_reference/`；随后同路径解验证直接记录到最早时延最大相邻跳变约362.20 ns，而几何时延最大相邻变化仅约0.000947 ns，见 `results/geometry_reference_validation/summary.json`。这是参考定义的适用边界，不等于所有变化都是数值错误，也不等于证明500 Hz在所有场景不足。

## V2定义

对固定基站发射阵列中心位置与无人机接收阵列中心位置，取它们的欧氏直线距离除以光速，得到 `tau_geo(t)`。该量只由当前收发位置决定，不查找或选择任何传播路径。即使直线被建筑阻挡，它仍是**几何参考距离对应的时延**，不是宣称存在真实LoS路径，也不是NLoS首径时延。

记 `a_p(t)` 为传播路径复系数：采用当前 Sionna `paths.a` 中尚未乘入路径总长度载波相位的系数，保留材料/极化/阵列响应；`tau_p(t)` 为路径绝对传播时延，`f_k` 为相对载频的子载波偏移。定义：

```text
tau_geo(t) = || rx_center(t) - tx_center || / c

H_geo[k,t] = sum_p a_p(t)
                  * exp(-j * 2*pi * (fc + f_k) * (tau_p(t) - tau_geo(t)))
```

每个 `a_p` 仍包含全部64个发射阵元的复系数，输出仍为 `[64,128]`。当前 synthetic-array 的阵元间相位由原阵列响应保留，不对每根天线单独去相位，不改变阵列相对几何。直接使用已乘载频相位的 `cir()` 输出再套上述公式会重复载频相位，必须避免。

当前配置为 `csi_reference="geometric_distance"`、`normalize_delays=False`。V2不是 `normalize_delays=True` 后再随意乘一个位置相位。实现 `rt_runtime/snapshots_geometry.py` 在原始路径系数与绝对路径时延上，一次性使用上述几何参考公式；非法路径不参与求和。载频与子载波频偏使用同一个参考。false表示关闭最早路径归一化，不表示输出绝对参考CSI。

## 数学一致性与恢复关系

在相同路径集和数值精度下，它与不进行时延归一化的绝对参考CSI满足：

```text
H_geo[k,t] = H_abs[k,t] * exp(+j*2*pi*(fc+f_k)*tau_geo(t))
H_abs[k,t] = H_geo[k,t] * exp(-j*2*pi*(fc+f_k)*tau_geo(t))
```

乘子对同一子载波的全部阵元相同，且模长为1。因此每个元素的幅度、整帧能量、同一子载波的阵列相对相位保持不变。每个子载波的矩阵奇异值以及按子载波非相干汇总的标准波束功率也不因这一公共相位改变；跨子载波相位和绝对定时参考则确实改变。它不是增益归一化、时间平滑或对困难样本的修改。

两种归一化目标的理论关系为：

```text
H_geo[k,t] = H_earliest[k,t]
            * exp(+j*2*pi*(fc+f_k)*(tau_geo(t)-tau_min(t)))
```

旧V1文件未保存每帧真实最小时延，不能仅凭旧H、路径数和位置精确恢复这个转换，也不能用估计频率斜率冒充真实最小时延完成正式重标注。V2因此使用已验证的路径级实现重新生成；旧V1数据及压缩缓存完整保留在 `data/candidate_v1_earliest/`，不混用。

同一几何定义适用于所有轨迹，不需要按每条轨迹首帧另选相位原点。它对统一刚性坐标平移/旋转不敏感，因为欧氏距离不变；但收发位置仍须在同一坐标系、同一单位下，并保持相同阵列中心约定。若以后增加基站，每条收发链路分别用自己的几何距离。

## 它需要哪些信息

仿真生成端知道每个时刻的位置，可以在不向预测网络输入位置的前提下构造H_geo标签。之后网络仅用历史H_geo、历史时间戳和未来查询时间预测未来H_geo，仍是**单CSI输入模型**，但任务应称为“几何直线参考下的CSI预测”，不能隐去预处理用到几何的事实。

实际系统若从原始测量构造同样的历史输入，需要历史收发距离或等效参考估计。要将预测的未来H_geo恢复为未来绝对参考CSI，还需要相应未来几何距离，例如来自已知导航计划、独立位置预测或定位系统；仅有未来时间戳不足以保证这一步可实现。定位误差会造成残余相位误差，毫米波等高载频下尤其敏感。

如果将真值未来位置只用于仿真标签定义，而不作为网络输入，这不等同于把未来观测直接泄漏给网络；但用它恢复未来绝对CSI并宣称端到端部署性能，就引入了额外的未来几何先验，必须明确报告。没有这些条件时，本轮结论仅针对H_geo目标。

## 稳定性与数值边界

几何参考沿连续运动轨迹连续，不因某条弱早到路径的开关重置。这消除了V1的一类参考跳变机制，**不保证CSI必然平滑、带限或容易预测**：

- 各路径的剩余长度是“实际传播长度减直线距离”，多径差分多普勒仍存在；NLoS绕行路径可以相对几何距离快速变化。
- 反射/绕射路径的可见性变化、材料相位、多径相消、深衰落与有限射线候选误差仍会影响复数H。
- 500 Hz是否足够必须对V2重新审计，不能继承V1的成功或失败数值，也不能仅凭移除公共相位就宣布无混叠。

实现应先将绝对路径时延和几何时延提升至float64，再相减并计算相位，避免先形成两个大的float32载波相位再相减造成额外精度损失。但这不能恢复上游几何追踪已丢失的精度：`paths.tau`若已是float32，其量化误差仍然存在。保持原始几何和物理模型，不使用平滑、截断或未来oracle相位对齐改善训练标签。

验证结果保存在 `results/geometry_reference_audit/` 和 `results/geometry_reference_validation/`。弱NLoS窗口相同路径解的几何参考与绝对参考乘单位相位结果一致（float64平均NMSE约−240.76 dB），增益差约2.84e-14 dB。但保持预测在0.5、2、5 ms的逐样本NMSE仍分别约−12.30、−1.06、+5.19 dB：参考切换得到解决，不代表残余相位变化已很慢，也不保证多步预测必然优于零或保持。

V2密集 `paths.npz` 和非网格查询均保存 `tau_geometry_s` 与 `tau_min_s`，后者仅作审计、不用于相位参考；非网格查询还附带路径数。来源记录见 `data/reproducibility/v2_geometric_snapshot_20260905.json`。正式运行目录沿用名字 `runs/main_v1/`，但其数据为V2，并从头按逐目标NMSE监督训练；旧试跑在 `runs/pilot_v1_history_mse/`。V2的压缩基、缓存及checkpoint不继承旧V1实验。
