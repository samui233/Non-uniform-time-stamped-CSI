# 中心单基站非均匀时间 CSI 数据集

本文依据实际配置 `data/dataset_config.json`、轨迹清单 `data/manifest.json` 与生成代码撰写。最终 RT 完成状态以每条路径的 `complete.json` 为准；存在 `H.npy` 不代表整条数据已经写完。训练与模型性能见对应运行目录，不在本文提前给出结论。

**版本边界：**当前正式 V2 数据位于 `data/routes/`，采用几何直线时延参考并保留1毫米镜面共面判定修复，120条轨迹已全部完成。`data/candidate_v0/` 保留镜面修复前版本；`data/candidate_v1_earliest/` 保留最早路径参考V1及其压缩缓存，均不参与正式训练/评估。下述完整性统计来自V2自身输出。最终运行目录仍命名 `runs/main_v1/`，运行名不代表物理数据版本。

## 最终数据摘要

密集CSI合计480120帧，验证/测试另有3456个真实离网格标签。422个未解析帧均在训练集，原始文件中保留。按完整历史与未来区间的标签可用性筛选，训练截止点296138/298284可用（99.28%）；验证与测试分别63918/63918可用。窗口可重叠，这些数字不是独立样本数量，也不是每个epoch读取量。

训练集拟合的复数PCA最终选择128维（展开为256个实数特征）。训练/验证的平均完整矩阵重建NMSE分别为−38.43/−37.45 dB，逐帧误差95分位转dB分别为−33.84/−33.20 dB；预测评价包含被舍弃的正交补误差，未把压缩后的目标冒充完整CSI。

4个预定验证片段的2000 Hz局部复核中，500 Hz锚点插值到真实1 ms中点的NMSE依次为−40.93、−40.53、−25.74、−17.93 dB。该检查只评价有限片段的采样分辨率，不证明全数据不存在混叠。其中一个遮挡片段的同网格重新追踪误差为−18.94 dB，说明有限射线搜索仍存在批次布局敏感性。全数据仍保留几何可见性切换与深衰落，不保证处处平滑。原始审计见 `results/data_audit/`、`results/sampling_audit/`。

## 数据用途

使用固定城市、固定基站和多种无碰撞运动轨迹，研究由任意数量、非均匀时间戳的历史 CSI，预测限定未来时间范围内的完整 CSI。当前只输入无线观测；位置、速度、姿态和 LoS 状态是生成依据与分析标注，不作为单模态模型的额外输入。没有生成本轮 RGB、波束扫描或 GUI 回放画面。

高密度 CSI 是基础真值。训练时从历史区间抽取观测；未选中的时刻不能当作模型已知输入。这样可以在同一条真实信道上控制数量、抖动、稀疏和缺失模式，不必为每一种观测模式重新生成整条信道。

## 轨迹组成与覆盖

共规划 **120 条、每条 8 秒**，六类各 20 条。每类预先分配 14 条训练、3 条验证、3 条测试，总计 **84/18/18 条**。这些是独立轨迹划分，不把同一路径的相邻窗口分散到训练和测试中。

| 类别 | 构造方式 | 实际速度范围（m/s） | 实际场景高度范围（m） |
|---|---|---:|---:|
| cruise | 普通直线巡航，允许小幅高度变化 | 7.55–12.65 | 35.19–68.02 |
| highspeed | 高速直线穿越 | 17.08–25.78 | 32.79–67.63 |
| sweep_turn | 椭圆弧大角度连续转向，允许升降 | 3.81–19.95 | 26.75–69.14 |
| uturn | 平滑折返，在折返点附近减速 | 0.57–20.30 | 31.88–70.99 |
| climb_descent | 水平前进与平滑爬升/下降组合 | 5.03–12.55 | 21.77–70.98 |
| occlusion | 建筑旁穿越，几何 LoS→NLoS→LoS | 7.06–11.98 | 29.10–41.26 |

所有路径的联合范围约 X∈[-111.38,112.64]、Y∈[-86.41,43.03]、Z∈[21.77,70.99] 米。允许规划边界更宽，为 X∈[-122,114]、Y∈[-89,44]、Z∈[18,75]，因此不能把允许边界当作已经完全覆盖的区域。

转弯类累计偏航范围约154–311度，折返类约165–176度。折返采用减速后反向的连续曲线，不是方向瞬时翻转。六类并非所有条件的笛卡尔积：当前高速、巡航、折返几何预检均以 LoS 为主；明确遮挡过渡集中在 occlusion 类。遮挡路径主要来自两条经检查的街区通道，**不代表均匀覆盖所有建筑或完全未见街区泛化**。实验应分组报告，不应据此宣称已经覆盖任意高机动遮挡组合。

路径由三次样条表示，位置、速度、加速度连续，保存 1000 Hz 的8001个时刻及样条系数；CSI 和非网格查询直接在样条上求位置、速度。约束为速度不超过27 m/s、加速度不超过22 m/s²、jerk不超过60 m/s³、距基站至少10米。姿态采用速度切线偏航、roll/pitch为零。它是**运动学测试轨迹，不是已经通过真实无人机动力学、倾角和飞控约束验证的飞行任务**。

### 碰撞检查的含义

障碍物来自原简化地图的保守三维 AABB 缓存，每个盒子各方向膨胀2米。按10 ms分段检查线段与膨胀盒相交；另外根据整条样条最大加速度为线段和连续曲线间偏差增加余量，上界为 `amax × 0.01² / 8`。三次样条每段加速度线性，因此可从结点计算其最大范数。速度和场景边界检查也加入间隔内余量。

这是相对于当前静态地图与缓存的保守无碰撞检查。它不覆盖未来新增动态障碍，不是任意城市真实地图的碰撞证明。每条 `trajectory.json` 保存实际余量、运动范围及预检结果；welded 网格保持原三角形空间表面，因此原缓存可继续作为保守障碍。

| 阵元间隔 | 水平、垂直均0.5波长 |

| 数据类型 | complex64 |

| 路径最大深度 | 3 |
| 每源发射搜索样本 | 32768 |
| 路径容量 | 2048×当前批量接收位置数，不是每位置保证有2048条路径 |
| LoS / 镜面反射 | 开启 / 开启 |
| 绕射 / illuminated-region | 开启 / 开启 |
| edge diffraction | 关闭 |
| 漫反射 / 折射 | 关闭 / 关闭 |
| 射线随机种子 | 42 |
| 场景合并 | merge_shapes=False |
| 项目级几何修复 | 镜面回溯共面距离容差1 mm，平方阈值1e-6 m² |

素材的无线材料名为 `itu_concrete`、`itu_brick`、`itu_glass`、`itu_very_dry_ground`、`itu_medium_dry_ground`，电参数由当前 Sionna 材料实现及载频确定。前期同配置审计中散射系数均为0；本轮不另外设置墙面散射，不启用漫反射。XML 的 RGB 反射颜色不是无线介电常数，也不能把视觉 diffuse BSDF 当作开启无线漫反射的证明。此数据不是包含一切传播机制的地面真值，而是指定 RT 模型的仿真结果。

保存的是频域信道传递系数，不乘入基站发射功率，不加入 AWGN、接收机估计误差或量化噪声。增益曲线定义为 `10 log10(mean(abs(H)²))`，对64×128元素取均值；它不是接收功率 dBm。

V2保留V1的几何求解修复：在实例创建后调用 `rt_runtime.apply_rt_fix(sim, tolerance_m=0.001)`。它只收紧镜面回溯中“命中另一三角面时”的共面接受条件；命中原候选三角面分支、原平面哈希、搜索预算、材料、场计算及传播开关不变。该修复针对当前场景发现的近重复地面反射候选，作用于路径几何求解，不是事后修改 H，也不保证所有场景都无数值突变。实现、原始/修正版哈希及局部证据见 [RT_FIX.md](RT_FIX.md)。

### 几何直线参考，不是绝对公共载波相位

当前配置为 **`csi_reference="geometric_distance"`、`normalize_delays=False`**。`rt_runtime/snapshots_geometry.py` 从原路径复系数和绝对时延出发，先转为float64，再减去收发阵列中心直线距离除光速的几何时延，最后同时计算载频和子载波频偏对应的相位并求和。保存H为complex64。这里false表示不再采用最早路径归一化，不表示最终输出没有任何参考变换。

几何直线即使被阻挡也存在，不能把该参考理解为NLoS情况下实际存在的LoS首径。仍保留阵列间相位、多径相对时延/相位、材料反射相位、幅度衰落与角度变化，不逐阵元去相位、不时间平滑。构造这种CSI需要对应时刻的几何信息；网络仅输入历史CSI和时间，恢复未来绝对参考CSI还需未来几何距离。完整定义和恢复关系见 [CSI_REFERENCE.md](CSI_REFERENCE.md)。

500 Hz 是本轮存储网格，不是已证明的无混叠采样率。几何参考不因弱早到路径开关而重置，但多径剩余相位仍可快速连续旋转：验证弱NLoS局部窗口的几何参考保持NMSE在0.5/2/5 ms约为−12.3/−1.06/+5.19 dB，不能将修复解读为“保证容易预测”。`sampling_resolution_audit.py` 在预先选择的验证轨迹局部窗口追加2000 Hz真实追踪，作为分辨率诊断；有限窗口频谱有泄漏，局部结果不能证明整条轨迹或所有未来场景无混叠。该审计插值只用于比较采样误差，不生成训练标签。旧V1审计位于 `results/sampling_audit_candidate_v1/`，不代表V2结果。

每个轨迹时刻重新计算几何路径，再从该位置的路径场计算单个OFDM时刻的CFR；500 Hz 来自外部轨迹时间。原CFR接口中的 `num_time_steps=1`、`sampling_frequency=1` 只是单时刻计算约定，不是把整段信道采样成1 Hz；V2路径级求和同样没有叠加时域Doppler外推。没有用单次追踪替代整段位置更新。

## 批量追踪与可复现性

每次将最多64个轨迹时刻作为同一静态场景中的被动虚拟接收位置批量求解，当前配置为8个工作进程共享一张GPU。工作进程数是执行参数，不改变上述物理模型。虚拟接收器不改变场景几何、不会彼此遮挡，仍对每个位置计算 CSI。这种方式共享源射线搜索，并把全局候选容量按接收位置数量放大以减少截断。

有限射线搜索不是解析穷举；固定种子和参数有助复现，但不保证不同 GPU、Mitsuba/Sionna 版本或不同批量布局逐位相同。正式帧保存后训练直接读取，不为每个epoch重新追踪。

`data/physical_config.json` 冻结完整66个 SimulationConfig 字段、CFR参数与运行时修复说明。生成器读取冻结字段，再以运行配置覆盖地图、深度、搜索样本数、路径容量、随机种子及基站位置/朝向；两份配置都需要保存。实际启动命令默认读取 `configs/dataset.json`，`data/dataset_config.json` 是数据侧定义，两者不得在恢复时不一致。

**其中 `source_sha256` 是首次冻结时的来源记录，不是当前生成器版本认证。**它包含早期生成器与配置哈希，应保留为历史证据。正式训练起点来源记录为 `data/reproducibility/final_training_snapshot.json`，由CPU脚本记录生成器、运行时修复、几何参考实现、配置、场景资产及软件版本，并明确与旧哈希的差异；不改写物理配置。脚本依据当前CSI参考定义标注版本，默认保存新的时间戳快照。当前代码仍依赖所列外部SimART脚本和冻结地图，不是全部复制到了工程目录中。

`figures/dataset/physical_config_resolved.json`、`source_provenance.json` 和 `config_snapshots/` 是绘图/早期导出时的辅助快照，可能早于 V1；几何轨迹图可继续使用，但这些文件不替代当前运行配置及新来源快照。

当前软件版本：Sionna-RT 2.0.1、Mitsuba 3.8.0、DrJit 1.3.1、PyTorch 2.11.0+cu128、NumPy 2.4.4、SciPy 1.17.1。具体重生成还需相同修复地图与本地 SimART 实现。

## 文件结构与读取

```text
data/
  dataset_config.json
  physical_config.json
  manifest.json
  reproducibility/final_training_snapshot.json
  routes/<traj_id>/
    trajectory.npz        # 1000 Hz位置、速度、加速度、jerk、四元数及样条
    trajectory.json       # 路径类别、划分、约束和运动统计
    H.npy                 # [4001,64,128] complex64
    time_s.npy            # [4001] 秒
    paths.npz             # count、los、tau_min_s、tau_geometry_s，均[4001]
    offgrid_queries.npz   # 仅验证/测试，真实H及查询时刻/count/LoS/两种时延
    complete.json         # 本路径全部写完后才生成
    energy.npy            # 后续压缩/投影阶段生成的完整H能量
    eligible_cutoffs.npy  # prepare_windows.py生成的合格截止点
    eligible_offgrid.npy  # 仅验证/测试，合格非网格截止点
  window_coverage.json    # 窗口准备阶段生成，不是RT完成即存在
  candidate_v0/          # 修复前候选归档，不用于正式实验
  candidate_v1_earliest/ # 最早路径参考及旧压缩缓存，不用于V2训练
```

每条主 CSI 约250 MiB，120条约29.3 GiB，另加非网格标签、轨迹、模型等文件。可以用 `np.load(path, mmap_mode='r')` 按需读取，避免一次载入全部复数矩阵。

验证/测试每条设置24个截止点，每个截止点4个连续随机未来查询，范围2–500 ms；36条合计3456个非网格查询。这些 H 由对应真实连续位置重新追踪，**不是在500 Hz矩阵之间插值生成**。`cutoff_s` 是时间网格上的历史截止点，`query_s` 是相对该截止点的未来秒数；绝对查询时间为两者相加。浮点格式不代表物理时间无限精度。

V2密集帧和非网格查询均附带 `tau_geometry_s` 与 `tau_min_s`：前者是目标使用的几何参考，后者仅作路径审计（无有效路径时为−1），不会用于重置V2相位。非网格文件另保存路径数，便于明确标签可用性。

当前历史跨度0.4秒，训练历史数量在4到32之间按整数抽取；4/8/16/32是固定预算评估点，不是训练仅有这四种长度。均匀、随机、突发聚集和中段缺失四种模式均保留历史区间两端，改变内部时刻分布。训练每个窗口抽取6个2–500 ms的主网格未来目标；固定评估预测时域为10/20/50/100/200/500 ms。历史来自500 Hz网格上的非均匀子集，并非连续任意时刻重新采样；真正网格外的未来查询另有RT真值。训练窗口在各轨迹内可重叠或重复抽取，分割独立性由整条轨迹划分保证。本数据可以在不重生成 H 的情况下改动历史数量、间隔和主网格查询，只需满足原轨迹时间范围。超出现有 off-grid 清单的非网格真值需要追加RT。

路径 split 在生成前固定。相似街区可能同时出现于各split，这是同一城市分布内的新轨迹测试，不是跨城或跨建筑几何外推。空间压缩基、归一化统计、模型参数只允许使用训练集拟合，超参数用验证集；最终测试不能反过来挑好看的路径。

### 窗口有效性与条件预测范围

原始 H 和未解析帧全部保留；有限射线预算下没有找到路径不等于已证明物理信道为零。主实验限定为可解析链路条件下的 CSI 预测：`prepare_windows.py` 要求截止点之前0.4秒至之后0.5秒的**整段密集帧**都具有正路径数、有限且严格为正的完整H能量。非网格实验还要求该截止点的4个真实查询H能量全部有限且为正。没有增益下限、跳变门限或模型误差筛选，弱但可解析的深衰落保留。

这是使用未来标签可用性的**离线数据资格定义**，不是可部署的在线筛选策略；其结论不涵盖未解析区间和断链预测。资格列表由所有模型共用，覆盖率按轨迹和split记录到 `data/window_coverage.json`。报告未生成之前不预报有效窗口数。模型的单样本归一化尺度只由实际观测历史完整H的平均Frobenius能量平方根计算，未来不参与；加载器对无效或极小数值尺度报错，不静默删样本或限幅。完整协议见 `benchmark/实验协议.md`。
