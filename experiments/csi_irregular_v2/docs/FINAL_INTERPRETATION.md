# 最终测试结果的解释

本页只读分析已冻结的测试预测、验证日志和相同数据窗口的目标元数据。没有删除、平滑、重加权或重新训练任何样本。Harmonic LS采用输入精度相关可辨识性判定修复后重新计算的结果，未使用已归档的别名病态版本。

## 核心判断

**流水线和连续查询接口已经跑通，但“所有场景上可靠预测完整CSI”尚未成功。** 各已完成方法的逐目标等权平均NMSE仍大于0 dB。作为量纲参照，全零预测对每个有效非零目标的NMSE恰为1，即0 dB，因此不能用这些正均值声称总体预测性能已经令人满意。

这不表示所有时刻都不可预测。保持法的中位NMSE为 -13.44 dB，90分位为 -2.26 dB，92.44% 的目标误差低于0 dB；但最终均值为 +31.10 dB。少数深衰落目标对相对误差均值有压倒性影响。

## 哪些目标主导了结果

保持法中，`occlusion_011` 贡献 99.750% 的全部逐目标NMSE之和。最大的一个目标贡献 63.397%，最高约0.1%的目标贡献 99.816%。

最坏保持目标为 `occlusion_011`，截止 2.848 s、预测提前 500 ms；目标完整能量为 4.002918e-12，预测误差能量为 2.354928e-05，预测功率高估 67.70 dB。目标为NLoS且窗口跨越LoS状态变化。

这里不是仅有180度相位误差：该目标的幅度NMSE几乎等于完整复数NMSE，主要失误是未预测到深衰落后的幅度降低。其它一些最坏目标虽然终点已处于NLoS、没有新的LoS切换，仍延续低能量状态；因此不能把所有失败简化为“切换那个瞬间”。

## 为什么验证集与测试集差别大

两个划分的典型目标能量接近，但尾部不同。验证目标最低能量 2.330622e-10，测试为 3.951984e-12。验证中能量低于1e-10的目标有 0 个，测试有 31 个。这里1e-10只用于描述分布，没有据此筛选或改分数。

更直接地，未来能量/已观测历史平均能量的最小值，验证为 2.296609e-03，测试为 1.126250e-07。测试出现了验证未充分覆盖的强到极弱的遮挡/衰落演化，分母可以小多个数量级。

每种场景只有三条验证、三条测试轨迹；按轨迹划分避免了相邻窗口泄漏，却不能保证少量独立遮挡轨迹具有相同的尾部分布。现有证据支持“有限场景覆盖与深衰落泛化不足”，而不是据此认定验证程序和测试程序计分公式不同。

## 为什么能量加权排名不同

逐目标平均先分别除以每个目标能量，极弱目标的大相对误差权重不减；能量加权则把物理误差能量总和除以真实能量总和，强链路主导结果。两者回答的问题不同，排名变化不是算术矛盾。

例如t-PatchGNN种子43的能量加权误差与典型样本明显较好，但在极弱目标上仍有严重过预测；Neural Flow的输出更保守，可能减轻这些尾部相对误差，却在多数强链路上接近零预测。不能因为它的等权均值更低，就解释成它恢复了更多CSI结构；也不能只选能量加权指标宣布整体成功。

种子17的验证一直接近零预测，测试预测能量中位仅为真实能量约1%，形状相关也很低；种子29/43则学到了较好的典型CSI结构。这是训练过程对随机种子敏感的直接证据，但三个种子同时改变初始化与训练窗口抽样，不能仅凭这些结果断言唯一原因是某个局部极小点。

种子17更小的测试等权均值也不代表其训练更成功：收缩输出能减轻少数深衰落的过预测，同时牺牲多数正常目标。应保留全部三种子的结果，不能删掉种子17、只展示29/43。

## 图与后续解释

主图使用自动纵轴范围，代码没有设定会裁掉极大值的固定ylim。修复后的Harmonic LS已纳入本页统计，正式图已从同一批更新后的结果重新绘制。

主实验使用1200个窗口，受控采样实验使用400个窗口；两组窗口并非同一个样本集合。在相对误差被少数深衰落目标支配时，窗口组成变化足以大幅改变均值。因此不能把主实验与受控实验跨表的分数变化解释成采样数量或模式的收益。数量/模式效应应只在受控实验内部，使用相同截止时刻和查询目标的配对条件比较，并结合逐轨迹区间。

这批结果足以说明：不规则CSI预测的难点不仅是时间编码，监督目标、可解析性、幅度动态范围、独立轨迹覆盖和优化稳定性都会决定结论。下一轮如继续改模型或数据方案，应明确当前测试集已经参与开发诊断，另留独立最终测试；不要反复对同一测试结果调参后仍把它当作未见测试集。
