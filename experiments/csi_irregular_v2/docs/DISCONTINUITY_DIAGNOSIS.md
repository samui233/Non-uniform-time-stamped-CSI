# 扩展轨迹中的大幅突变诊断

2026-09-06。仅使用训练轨迹定位问题，未据测试预测成绩选择数据。以下诊断数据位于 `results/discontinuity_audit/`，脚本为 `discontinuity_audit.py`；原始主数据未被平滑、限幅或删除。

## 现象

扩大轨迹覆盖后，`sweep_turn_005` 在5.620→5.622秒出现约11 dB增益下降，`highspeed_016` 在6.532→6.534秒有类似约10 dB下降。两帧均有LoS。这不同于前期建筑遮挡的渐变入影/出影，不能仅以“真实遮挡”解释。

围绕每个事件固定±20 ms、间隔2 ms重新追踪，同一位置比较传播开关及四倍搜索预算。下表是该次独立重追踪结果；有限候选搜索使它与原主数据并非逐位相等。

| 条件 | sweep_turn_005 相邻增益变化 | highspeed_016 相邻增益变化 |
|---|---:|---:|
| 原设置 | -10.55 dB | -10.36 dB |
| 搜索射线增加4倍 | -11.75 dB | -10.96 dB |
| 关闭 illuminated-region 绕射 | -10.10 dB | 未测 |
| 关闭全部绕射、保留镜面反射 | -11.39 dB | -10.49 dB |
| 关闭镜面反射、保留绕射 | +0.0010 dB | -0.0003 dB |
| 仅LoS | +0.0025 dB | -0.0039 dB |

提高预算没有消除问题，绕射开关不是主因，异常与镜面路径有关。

## 逐路径证据

在转弯事件前，约19条单次地面反射的交互类型、物体、时延和反射位置几乎相同：反射点集中在 `(-36.10,-42.13,0.1524)` 米附近，位置仅毫米差异，单路径平均阵元功率约-96 dB。相干叠加这些近重复项后，整体增益被抬到约-70 dB，而独立LoS约-81 dB。后一帧这些近重复项大量消失。

高速事件也出现了同一类近重复单次地面反射，位置约 `(-26.79,3.22,0.152)` 米，单条约-95 dB。其LoS自身变化仅约0.004 dB。

这表明巨幅增益不是一条物理反射路径突然增强十余dB，而与多个候选收敛到近乎相同反射路径后被重复计入有关。逐路径 JSON 保留交互编码、物体编号、反射顶点、时延和功率，供进一步核查。

## 根因定位与两种修复尝试

Sionna候选生成通过平面哈希去重，当前法向量量化尺度为 `1e-5`，平面距离为1 mm。Image Method回溯时，如果命中的三角面不是候选原三角面，会检查两次镜像位置是否接近；原条件是平方距离小于 `1e-4`，即允许镜像点相差1 cm。

因此，候选阶段被区分的近共面三角面，在后处理阶段可能全部作为同一命中面的可接受候选留下，形成近重复反射。这是**候选去重精度和镜像共面接受尺度不一致**的数值几何问题，现有实验强烈支持这一解释。

1. 给全部PLY启用 `face_normals=true` 的独立场景副本没有改善，转弯事件仍约11 dB。代码使用 `si_scene.n` 几何法线，不能把原因简单归为视觉平滑顶点法线。Mitsuba的[官方PLY参数说明](https://mitsuba.readthedocs.io/en/stable/src/generated/plugins_shapes.html#ply-stanford-triangle-format-mesh-loader-ply)用于核对该开关含义。
2. 将平面哈希尺度放大10倍能消除主要重复项，但会合并原本不同的近邻平面，不作为首选正式方案。
3. **更合适的方案是只收紧Image Method的共面镜像接受条件到平方距离 `1e-6`，即1 mm。** 原候选命中确切三角面的接受分支保留，不改地图位置、顶点、材料、传播开关、平面哈希或最终CSI数值。

诊断用独立加载的 `ImageMethod` 模块，只改一处比较常数；未修改安装环境的共享Sionna源码。复制文件保留NVIDIA的原版权和Apache-2.0标记。由于DrJit会读取函数源码转换控制流，修改后的模块使用独立真实文件路径，避免动态exec仍从原文件读回旧阈值。

## 1 mm条件的验证

| 事件 | 32768搜索样本 | 131072搜索样本 |
|---|---:|---:|
| 转弯轨迹原异常点 | -0.152 dB | -0.041 dB |
| 高速轨迹原异常点 | -0.067 dB | -0.086 dB |
| occlusion_000 入影，0.814秒 | -0.083 dB | -0.093 dB |
| occlusion_000 出影，6.820秒 | +0.063 dB | +0.070 dB |

遮挡入口仍为LoS→NLoS，出口仍为NLoS→LoS，平滑衰落机制并未因该修正消失。遮挡窗口所有相邻2 ms增益变化最大约0.20 dB。更严格的0.1 mm条件在转弯四倍搜索情况下会对另一个位置的地面反射更敏感，因此暂选与平面距离哈希同尺度的1 mm，不追求越小越好。

这些是有限训练样本上的定位和验证，不保证全地图所有多次反射/绕射候选都已完美去重，也不证明所有未来数据没有真实快速衰落。正式数据必须使用固定修正版重新追踪，并再次进行整体质量与数值收敛检查。**修复前的重复路径数据不应直接用于正式训练，更不能把修复前后结果混合作为同一物理数据版本。**
