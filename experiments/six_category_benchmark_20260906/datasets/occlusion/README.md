# 第六类训练数据视图

原始数据来自 `data_occlusion_v3/`。60 条轨迹按 20 个空间通道分组，保留训练 42 条、验证 9 条、测试 9 条的原划分。相同通道的变体不跨集合。

本目录是真实的新目录。原始 CSI、路径元数据、轨迹及非网格真值以符号链接读取；系数、能量、残差和可用窗口索引全部保存在本目录的新文件中。准备前后核对原数据文件大小、修改时间及小文件 SHA-256，没有修改原始数据。

## 表示选择

所有 CSI 都保留完整复数定义。神经网络使用无中心化复数 PCA 系数；原幅度不改变，输入使用历史窗口能量归一化，完整矩阵评价保留子空间外残差。

在开训前，仅根据训练/验证集的重建误差判断表示是否充分。每条轨迹分层抽样 128 帧审计，没有使用测试数据选择表示。拟合时每条训练轨迹同等帧数、每帧按单位 Frobenius 能量加权。

| 候选 | TRAIN 平均 / P95 NMSE (dB) | VAL 平均 / P95 NMSE (dB) | 判定 |
|---|---:|---:|---|
| 仅新 TRAIN 拟合 128 | −48.93 / −43.96 | −16.61 / −12.17 | 验证集不达标 |
| 旧 V2 公共 128 | −23.18 / −16.06 | −25.19 / −16.37 | 训练集平均不达标 |
| **仅新 TRAIN 拟合 256** | **−80.73 / −75.73** | **−36.82 / −31.25** | **采用** |

既定判定标准为平均重建 NMSE ≤ −25 dB、P95 ≤ −15 dB。初始 128 维候选的全部派生文件保留在相邻的 `occlusion_candidate128/`，候选审计保存在 `../../basis_candidates/`。测试集仅在表示冻结后执行投影及可读性检查，未据其结果调整 rank。

最终 basis 为 `[8192,256]` complex64，网络特征维数为 **512 个实数**。前五类仍使用原来的公共 128 维复数基（256 个实数）；第六类的所有模型均使用同一个新 256 维复数基。跨类别的网络输入维度不同，因此运行开销不能仅归因于场景，模型比较应以各类别内部为主。

## 可用性

- 密集系数覆盖全部 60 条、75,060 帧。
- 训练/验证/测试可用截止点分别为 33,642 / 7209 / 7209，无零路径标签窗口损失。
- 验证与测试各有 216 组、864 个实际非网格目标。
- 已分别读取三个集合各 600 个随机窗口，涵盖历史 4–32 帧和四种时间采样模式，并读取全部非网格组。
- `READY.json` 保存最终 basis 哈希、训练/验证选择依据、数据配置与准备代码哈希，可作为调度器启动标志。

原始遮挡数据中的深衰落和陡峭变化全部保留。重建误差足够低并不保证未来 CSI 可预测，也不代表已消除射线模型的边界近似或瞬时多径变化。
