# 六类场景实验的主要结论与解释

本说明解读本轮测试中的主要现象。全部方法、预测提前量、随机种子和受控条件的结果见 [完整实验报告](RESULTS_CN.md)；数据、方法及训练协议见 [方法说明](METHODS_CN.md)。这里的结论针对当前固定城市、单基站和几何距离参考 CSI，不代表对原论文方法的普遍排名。

## 1. 能否学到比保持更好的预测？

可以，但**不是把任意连续时间模型接到高维 CSI 上都能做到**。

下表采用三个训练种子的平均误差：先在相同测试目标上平均线性 NMSE，再转成 dB。比较的是单个模型的平均性能，不是三个模型的预测集成。

| 场景 | 保持 / dB | Observed Flow / dB | 相对保持的差值 / dB |
|---|---:|---:|---:|
| 巡航 | −12.375 | −14.440 | −2.065 |
| 高速 | −7.945 | −8.921 | −0.976 |
| 连续转弯 | −10.505 | −11.295 | −0.789 |
| 折返 | −9.070 | −9.816 | −0.747 |
| 爬升/下降 | −11.600 | −13.025 | −1.425 |
| 遮挡 | +1.577 | −1.824 | −3.401 |

Observed Flow 在六类场景的总体均值上都优于保持。在六类、六个预测提前量构成的 36 个条件中，有 34 个均值低于保持；另外两个是高速类的 10 和 20 ms，差异分别约为 +0.012 和 +0.004 dB，表现相近。这些计数不能解释为 34 次独立统计检验。

前五类中，收益通常随预测提前量增加而更明显。例如，巡航类相对保持的差值从 10 ms 的 −0.053 dB 扩大到 500 ms 的 −2.766 dB。很短的提前量下，最后一次真实 CSI 本身已经是很强的预测；较长提前量下，外推动态才有更多发挥空间。

但 CRU、Latent ODE、Latent Flow 和 t-PatchGNN 这四种原方法的本次适配，在前五类中均落后于保持。模型已经完成优化、NMSE 为负，并不等于利用好了历史中的动态信息。负 NMSE 只表示优于输出零矩阵。

Observed Flow 保留最新观测及从真实时间戳估计的局部变化率，原潜变量框架则需要先压缩历史、再重建当前及未来状态。结果与“保留当前观测有助于高维 CSI 预测”这一解释一致。它们同时存在编码器、参数量和输出结构差异，本轮不是只替换 Flow/ODE 核心的严格消融，不能将差异全部归因于某一个模块。

## 2. 低维压缩不是当前主要精度瓶颈

在与主测试完全相同的真实目标上，固定 PCA 的平均重建 NMSE 分别约为：巡航 −39.53、高速 −36.66、转弯 −36.85、折返 −35.69、爬升/下降 −39.45、遮挡 −46.41 dB。

这些数值远低于模型的预测误差。因此，当前部分方法的较弱表现不能主要解释为 PCA 已经丢掉了大部分可预测 CSI。更需要关注历史编码、当前状态保留、动力学外推与训练目标。这个检查不等于证明任意降维都无害，也不直接定位到某一层网络。

完整数值见 `tables/representation_floor.csv`。该表只评价冻结空间基的重建误差，没有用测试集重新拟合或选择基的维数。

## 3. 简单方法的价值取决于运动场景

巡航类中，线性外推为 −14.00 dB，Kalman 为 −14.20 dB，已明显优于保持；Observed Flow 为 −14.44 dB。局部趋势可以解释这一场景中的很大一部分收益。

高速类中，线性和 Kalman 分别为 −5.06 和 −5.59 dB，反而弱于保持的 −7.94 dB。折返类也存在同样的排名变化。把较长历史窗口中的一个趋势持续外推，并不总能适应快速变化的 CSI。

因此，“保持应当是最差的方法”不是合理的前提。保持既是强参照，也能帮助检查复杂模型是否损失了原本很准确的最新观测。轻量 Local dynamics 在前五类的总体均值也都低于保持，说明当前数据中确实存在可学习的局部动态，但复杂度本身并不保证收益。

单频 Harmonic 的误差随查询提前量存在明显起伏。在稀疏、不规则历史上拟合单一频率，可能存在频率歧义或单频假设失配；本轮结果不足以将这种起伏唯一归因为其中一个原因。它采用固定的历史频率搜索规则，没有按测试成绩调整频带。

## 4. 目前更显著的是观测新鲜度，而非内部间隔的不规则性

以下受控结果固定使用种子 17，各条件共享相同目标窗口，不能与主实验的 600 窗口均值直接相减。

以 Observed Flow 为例，把历史观测从 4 个增加到 32 个，六类中的改善约为 0.05–0.58 dB。增加观测有帮助，但在当前条件下并没有产生数量级上的提升。

| 场景 | 4 个观测 / dB | 16 个观测 / dB | 32 个观测 / dB |
|---|---:|---:|---:|
| 巡航 | −14.009 | −14.299 | −14.309 |
| 高速 | −8.704 | −8.752 | −8.774 |
| 连续转弯 | −11.213 | −11.398 | −11.410 |
| 折返 | −9.185 | −9.556 | −9.685 |
| 爬升/下降 | −12.803 | −13.298 | −13.385 |
| 遮挡 | −1.847 | −1.901 | −1.901 |

固定 16 个观测、保持首尾端点不变时，随机、均匀和中间缺测的差异总体较小。成簇观测会使部分场景变差，例如巡航约退化 0.42 dB、爬升/下降约退化 0.37 dB。完整四种模式及所有方法见 `sampling_pattern_and_count` 图与汇总 CSV。

仅将内部历史时间标签改成均匀标签，Observed Flow 在六类中的变化不超过约 0.024 dB；加入 20 ms 内部时间扰动时，变化不超过约 0.054 dB。这个实验固定了首尾时间，并保留真实查询时刻，**没有测试整个传感器时钟偏移或最新观测时间错误**。这种弱敏感性可能说明模型较依赖最新 CSI，也可能说明当前内部扰动的额外影响有限；不能据此得出“真实时间戳不重要”的普遍结论。

相比之下，最近观测停在截止点前 100 ms 时，Observed Flow 在六类中退化约 0.88–2.02 dB；遮挡类从 −1.90 dB 变为 +0.12 dB。该实验同时增加了从最新可用 CSI 到目标的外推距离，并改变历史覆盖范围，反映的是更新延迟/近期观测缺失，不是单纯的时间标签误差。

这一点并不适用于所有算法。Harmonic 在均匀伪时间下退化约 5.42–18.33 dB，说明依赖物理频率拟合的方法尤其需要正确的观测时间。另一方面，部分本就接近零输出的网络对时间扰动也几乎不敏感，这不能当作良好鲁棒性的证据。

因此，**对本轮表现较可靠的 Observed Flow，观测新鲜度比内部采得更密或更规则更关键；对显式频率拟合，错误的内部时间也会造成严重问题。** 不同模型的时间敏感性不能混为一谈。当前证据还不足以支撑“复杂非均匀时间建模带来很大预测增益”的强结论。

## 5. 可以查询真实离网格时刻，但不能把两组均值差当作纯离网格惩罚

离网格标签是额外射线追踪得到的真实 CSI，不是对已有 500 Hz 序列插值。Observed Flow 在六类离网格测试中的总体 NMSE 均为负，也均低于相同目标上的保持：

| 场景 | 离网格保持 / dB | 离网格 Observed Flow / dB |
|---|---:|---:|
| 巡航 | −10.442 | −12.797 |
| 高速 | −6.102 | −7.260 |
| 连续转弯 | −8.481 | −9.361 |
| 折返 | −7.398 | −8.127 |
| 爬升/下降 | −10.024 | −11.832 |
| 遮挡 | +3.141 | −0.832 |

这证明了本轮已实现并实际测试连续查询接口。它不意味着任意长的预测时域都可靠：本轮历史跨度为 0.4 秒，未来范围截至 0.5 秒，观测数量主要覆盖 4–32 个。

主测试与离网格测试的截止窗口、查询提前量分布不同，不能将两个均值直接相减后声称“偏离采样网格导致了这么大的损失”。按提前量分段的离网格结果保存在 `tables/offgrid_horizon_bands.csv`。

## 6. 遮挡类的平均 NMSE 改善，伴随着明显的幅度收缩

这是本轮最需要谨慎解释的结果。

遮挡类主测试共有 3,600 个查询条目，其中 112 个目标相对最后观测下降至少 10 dB，占约 3.11%，却贡献了保持法总逐目标 NMSE 和的约 51.95%。这里是查询条目数，不是 112 个独立物理事件；滑动窗口可以重复覆盖相邻或相同物理时刻。

Observed Flow 降低了衰落组中的误差，但不是所有传播状态都改善：

| 分组或指标 | 保持 | Observed Flow |
|---|---:|---:|
| 总体逐目标平均 NMSE / dB | +1.577 | −1.824 |
| 稳定 LoS 组 NMSE / dB | −9.005 | −4.443 |
| 相对最近观测下降至少 10 dB 组 NMSE / dB | +13.804 | +4.299 |
| 能量加权 NMSE / dB | −6.899 | −4.043 |
| 逐目标 NMSE 中位数 / dB | −6.526 | −2.956 |
| 平均增益绝对误差 / dB | 2.101 | 10.856 |
| 平均有符号增益误差 / dB | −0.182 | −10.721 |
| 平均结构相关性 | 0.841 | 0.834 |

增益误差是预测矩阵总功率相对于真实矩阵总功率的 dB 差；负值表示低估。结构相关性是归一化复内积模平方，忽略公共相位与整体尺度，仅作为结构诊断，不代替复数 CSI 的 NMSE。

这些数值说明 Observed Flow 的总体改善相当一部分来自降低高估弱信道的风险，同时对不少目标产生幅度收缩。它在稳定 LoS、能量加权误差和中位数上均弱于保持。因此，不能只看 −1.82 dB，就宣称遮挡类的完整 CSI 预测已经很好地解决。

原 Latent Flow 在遮挡类接近 0 dB，但平均增益偏差约为 −43.79 dB，结构相关性约为 0.008，体现出接近零输出的退化。CRU 和 Latent ODE 也存在明显的低幅度/低相关性问题。相对保持降低平均误差，不等于恢复了更多真实信道信息。

t-PatchGNN 在遮挡类虽然得到约 −0.005 dB 的负 NMSE，但平均增益偏差约为 −32.95 dB，结构相关性仅约 0.020，同样不能解释为有效恢复了 CSI。这也直接说明“至少得到负 NMSE”只能作为很弱的检查条件。

这种结果与逐目标 NMSE 对低能量目标的敏感性，以及不确定未来下均方回归向均值收缩的倾向一致。不过，本轮没有通过单独改变损失、潜状态或数据分布来分离原因，不能把所有退化唯一归因于损失函数。

所有深衰落均保留在训练和总体测试中。分组用于理解结果，没有根据模型误差删除“异常”目标。完整有符号增益诊断见 `tables/gain_diagnostic.csv`。

## 7. 当前成果与后续取舍

本轮已经能用不等数量、非均匀时间戳的历史 CSI 查询未来指定时刻，并在真实离网格目标上评价。前五类存在明确可利用的动态，保留最新观测的结构和局部趋势方法比原潜变量适配更可靠。

后续单模态实验可以保留 Observed Flow、保持和简单动态方法作为核心对照，同时继续记录完整复数 NMSE、增益误差和结构相关性。对遮挡类，应先明确希望预测的是完整瞬时 CSI、可靠的增益变化，还是带不确定性的未来信道；不能靠压低输出获得较好平均 NMSE 后就认为目标已达到。

如果要修改模型或训练目标，应使用新的最终测试集评价。本轮每类只有三个独立测试轨迹或空间通道组，现有聚类区间只能反映这些组的变化，不能替代更大规模跨场景验证。前五类的测试也延续自前期开发，并非全新盲测。

最后，遮挡组难预测并不直接证明图像必然有效。图像能否在信道变化之前提供增量信息，需要使用真正对齐的视觉历史单独验证；本轮模型没有输入图像、位置、速度、姿态或未来几何信息。这里的预测对象是经过几何距离参考处理的 CSI，恢复绝对传播相位另需相应的几何时延。
