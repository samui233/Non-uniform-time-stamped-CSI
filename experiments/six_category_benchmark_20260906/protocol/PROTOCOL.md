# 六类独立数据集的完整模型比较

实验标识：six_category_v1。既有目录和结果不覆盖；最终 GitHub 目录为
`experiments/six_category_benchmark_20260906/`。

## 数据与问题定义

分别训练、分别测试巡航、高速、大范围转弯、折返、升降、短遮挡穿越六类。
前五类沿用 V2，各14/3/3条训练/验证/测试轨迹；第六类使用新occlusion_v3，
按空间通道整体分42/9/9条，对应14/3/3个通道，同通道的三个变体不跨集合。

使用几何距离参考的完整复数CSI：生成时消除TX-RX中心直线路径对应的公共传播相位，
不是直接预测未经参考变换的绝对载波相位。不对预测结果进行oracle相位对齐，
不平滑标签，不裁剪衰落，不按照模型误差删除样本。
完整矩阵64根天线×128个子载波，密集标签500Hz，历史跨度0.4秒，未来最长0.5秒。

前五类保留原TRAIN拟合的共同PCA128，F256；该basis含其他旧TRAIN类别信息，
因此“分类训练”指监督模型优化，不声称预处理仅看到各自类别。
第六类仅用新42条TRAIN拟合PCA256，F512。
其rank128在VAL重建floor为−16.61dB，rank256为−36.82dB；在所有正式TEST之前依据TRAIN/VAL选择。
每个类别内所有学习方法共享同一表示，最终完整矩阵误差保留PCA正交残差。
类别之间输入维度、轨迹数量和空间覆盖不同，不能将所有差异都归因于运动类型。

## 模型与训练

六种学习方法：CRU、Latent ODE、潜变量Neural Flow、t-PatchGNN、Observed-state Flow、Local Dynamics。
前四者为已核对源代码的CSI适配；Observed-state Flow是保留当前复系数和历史变化率的明确架构适配，
Local Dynamics是321参数的可学习局部外推诊断，不冒充原论文方法。
这个比较不是只替换连续时间核心、其余架构完全相同的消融。

每类每方法seeds17/29/43，总共108组权重。
复用已有匹配数据/源代码/协议的15个潜变量Flow、15个Observed-state Flow以及3个Local Dynamics；
复用记录与原checkpoint哈希见各目录REUSED.json。其余75组补齐训练。

每轮4,000个随机训练窗口，600个固定VAL窗口，最多60轮；以VAL逐目标完整矩阵NMSE选择best。
学习率0.0003，AdamW，原历史能量归一化，不使用未来统计量作为输入。
潜变量Neural Flow早停耐心10轮（与复用实验一致），其他12轮。
CRU batch512；ODE/潜变量Flow/Local256；Observed128；tPatch在F256用64，在F512用16。
观察数/epoch一致，但模型间batch不同，优化步数不是完全一致。
CRU内部FP32、关闭TF32，经TRAIN同权重数值测试；相关证据见CRU_PRECISION_DECISION.md。
其他方法保留原适配器的内部数值处理并使用原训练引擎BF16 autocast。

## 固定实验

训练/VAL窗口种子分别使用训练种子和917，TEST固定1917。
所有目标、历史数量、时间戳和数据身份通过配对检查，不按TEST分数调整超参数或选种子。

1. 主实验：每类600个窗口，4–32个混合分布历史观测，未来10/20/50/100/200/500ms，全部3种子。
2. 真实非网格查询：使用额外射线求解的全部heldout查询标签，不插值；全部3种子。
   截止窗口和提前量分布与主实验不同，两个均值之差不是严格配对的网格效应。
3. 历史时间分布：相同200个目标窗口、16个历史点，uniform/random/bursty/dropout，固定训练种子17。
4. 历史数量：相同200个目标窗口、random分布，4/8/16/32个点；16点复用上一个实验。
5. 报告时间戳：相同200窗口、random16，clean/内部时间均匀化/内部20ms抖动。
   保留首尾锚点，扰动后同时重排压缩和完整历史；不覆盖整体传感器时钟偏移。
6. 近期观测缺失：相同200目标窗口，16点实际分布于[-0.4,-0.05]或[-0.4,-0.1]秒，
   重新按真实可用历史归一化。观测年龄与距最近观测的预测时长同时增加，不能仅称时戳误差。
7. 遮挡与深衰落：主实验所有样本保留，按历史/未来是否发生LoS切换、
   真实目标相对最近观测的能量变化分组。下降至少10dB是预设描述阈值，不用于筛选训练或测试数据。

每项都包含完整矩阵保持、线性外推、Kalman、历史拟合的单频谐波参照。
Kalman噪声比例仅在各类别VAL600上选取，后续固定；谐波频率只拟合历史，不按TEST调参。

## 统计与交付

主指标为每个目标完整复数CSI的线性NMSE均值再转dB；跨种子也在线性误差域平均，非预测集成。
另列中位误差、负NMSE比例、能量加权误差、结构相关度和增益误差，观察深衰落尾部及输出收缩。
前五类按轨迹、遮挡类按通道组bootstrap，不把相邻窗口或同通道变体当独立轨迹。
各类别只有3个独立TEST轨迹/通道簇，区间与泛化结论均需谨慎。
同模型/条件的全部种子、正NMSE和不利结果保留，不人工修饰曲线。
