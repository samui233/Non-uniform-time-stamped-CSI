# CRU 内部数值精度决策（所有正式 TEST 之前）

原 CRU 的连续线性高斯状态及协方差更新使用 FP64 矩阵指数，是本轮主要计算瓶颈。
只改变计算精度为 FP32、关闭 TF32，原方程、结构及参数数量均不变。

输出相对误差4.65e-7，梯度相对误差1.66e-6，完整矩阵NMSE相同到记录精度。
协方差保持正定、没有非有限值；繁忙GPU上的训练权重测时改善约1.18倍，初始权重约2.24倍。
不能由该测时承诺所有训练固定加速倍数。

依据是数值与资源审计，不是 TEST 模型表现。正式全部18个CRU统一使用该精度。
已经启动但未完成的巡航FP64三种子训练归档到 `diagnostics/cru_fp64_pilot/`，不作为正式结果；
CRU从原种子重新初始化训练，其他未改结构的方法按原checkpoint断点继续。
