# 本次六个网络究竟在预测什么

本文说明实际运行的代码，不把方法名称等同于原论文全部实现。六个网络采用相同的 CSI 表示、归一化、输出形式和评估指标，但内部结构、参数量与计算量不同。

## 1. 输入、目标与维度

输入仅为历史 CSI、对应真实时间戳及 padding mask，没有位置、速度、姿态、RGB 或未来运动信息。一个样本的历史覆盖 0.4 秒，最近一次观测记作相对时间 0；训练中历史观测数量在 4–32 之间变化。查询时间作为显式输入，预测接下来 0.5 秒范围内给定时刻的 CSI。

数据是 **3.5 GHz、基站 8×8 阵列、无人机单天线、128 子载波、30 kHz 子载波间隔**的复数 CSI。它采用生成器的几何收发距离相位参考，已去除该参考距离在载频及子载波上的确定性传播相位，不是未经处理的绝对载波相位 CSI；没有对时间序列做平滑。恢复绝对相位需要对应几何时延。

网络不直接在 16,384 维实数空间运行，而是先使用固定复数正交基压缩，再重建完整矩阵：

| 环节 | 前五类 | 遮挡类 |
|---|---|---|
| 单时刻完整 CSI | 64×128 复数，即 8,192 个复数 | 相同 |
| 固定复数基 | 8,192×128 | 8,192×256 |
| 压缩系数 | 128 复数 | 256 复数 |
| 实、虚部交错展开后的特征维度 F | 256 | 512 |
| 历史输入 | `[B, L, F]`，L 为批内补齐后的长度 | 相同形式 |
| 时间戳 / mask | `[B, L]` / `[B, L]` | 相同 |
| 查询时间 | `[B, Q]` | 相同 |
| 网络输出 | `[B, Q, F]` | 相同形式 |
| 重建输出 | `[B, Q, 64, 128]` 复数 | 相同 |

这里 B 是 batch size，Q 是查询数量。训练时 Q=6，查询点从未来密集时间网格中随机抽取；主测试固定六个查询时域。网络可接收不同的查询数量，但实验结论只覆盖已测试的历史长度和预测范围。

前五类共享早先从原始混合训练划分拟合的压缩基，各类别网络优化分别进行；因此是“按类别训练预测器”，不是“包括表示学习在内的一切都按类别独立拟合”。遮挡类使用新版数据的独立压缩基。基的拟合未使用测试集。

完整重建位于固定子空间中，压缩丢失的分量不能被网络恢复。损失中计入这部分投影残差，测试也在完整 CSI 上计算误差，不只评价压缩系数。保持法直接使用完整历史 CSI，因此不是人为削弱的低秩保持参照。

## 2. 归一化与历史中心化

每个窗口用最后一次观测的压缩系数范数进行归一化，对该窗口的历史和目标使用同一尺度；目标能量和投影残差能量同步换算。该尺度只依赖过去，既不用未来真值，也不用整段历史的能量统计给模型额外传递信息。

随后，将每一个历史系数向量减去最后一个历史向量，构成相对变化序列。最近观测本身作为独立的输出锚点保留。编码前另乘固定的 `sqrt(F/2)` 数值尺度，输出修正量再除回；它不是随样本变化的额外归一化。测试时逆变换尺度，再用固定基重建完整 CSI。

这样，网络的历史分支主要处理“之前相对于现在如何变化”，而不是反复重建当前已经知道的 CSI。不过，中心化本身不保证网络一定利用历史，仍需历史干预实验来检验。

## 3. 统一的复数仿射输出头

令 `z_last` 为归一化后的最新复数系数，网络针对每个查询产生一个实数向量 `raw`。它经过固定尺度还原得到复数修正候选 `delta`，同时通过 `Linear(F, 2)` 产生一个复数标量 `alpha`。

实际输出结构为：

```text
gate = (query_time - last_observed_time) / 0.1
parallel = sum(conj(z_last) * delta) / sum(abs(z_last)**2)
delta_perp = delta - parallel * z_last
z_pred = z_last + gate * (alpha * z_last + delta_perp)
```

这等价于“最新 CSI × 一个整体复数倍率 + 复数修正量”，在代码中先作用于压缩系数，再线性重建为完整 CSI。倍率对同一查询的所有系数共享，可以改变整体幅度和公共相位；正交修正量改变空间与频率结构。将修正量沿最新向量的分量剔除，可以减少倍率分支与加性分支的重复表达。

`gate` 是查询时间差除以固定的 0.1 秒，不是截断到 0–1 的门。在零预测时距，输出严格回到最新系数；这不表示任意时距的增益必然线性变化，因为 `alpha` 和 `delta` 本身也依赖查询。倍率层零初始化，但修正分支并非整体零初始化，因此初始网络不保证所有查询都等于保持法。

## 4. 六个骨干网络

### CRU

每个时刻先通过 `F → 64 → 64` 的 Tanh 编码器，输出 16 维观测均值和 16 维正观测方差。连续—离散 Kalman 核维护 32 维潜在状态及其协方差结构：观测之间按真实时间差传播，观测到达时更新，再向查询时刻传播。状态均值经 `32 → max(128,F) → F` 解码，进入统一仿射头。

本次使用 FP32 的连续递推/协方差计算，禁用该部分混合精度。它包含可学习的不确定性中间量，但本实验最终评价的是点预测，并未验证输出置信区间是否校准。核心来自 [Continuous Recurrent Units 官方实现](https://github.com/boschresearch/Continuous-Recurrent-Units)。

### Latent ODE

识别网络从后向前读取历史：64 维连续隐藏均值在相邻观测之间用 ODE 推进，再以 ODE-GRU 更新结合当前 CSI 与有效性标记。均值/标准差状态合并为 128 维，通过 MLP 产生 32 维潜在均值和尺度。识别 ODE 每个区间使用两步 RK4。

本次只取潜在均值作为确定性状态，从编码器参考时刻演化到每个查询时刻；生成 ODE 为 `32 → 64 → 32`，使用 24 步 RK4。再通过共享形式的 CSI 解码器输出 F 维向量。未进行潜变量随机采样，也没有加入 KL 损失，因此不能把它称为原始变分目标的完整复现。参考 [Latent ODE 官方实现](https://github.com/YuliaRubanova/latent_ode)。

### Flow

使用连续时间 coupling flow 与 LSTM 识别历史。隐藏状态为 64 维，LSTM 输入包含 F 维观测及 F 维有效性标记；相邻观测的隐藏状态先经时间条件 flow 变换，再做 LSTM 更新。识别器输出 32 维潜在均值及尺度，本次同样只使用均值。

生成端为两层 coupling flow，将潜在状态直接映射到查询时刻，不需要像 ODE 那样逐步积分；随后 `32 → max(128,F) → F` 解码并接统一头。flow 隐藏层为 `[64,64]`，使用上游 `TimeLinear` 时间函数。核心来自 [Neural Flows 官方实现](https://github.com/mbilos/neural-flows-experiments)，本实验没有照搬其原始随机训练目标。

### t-PatchGNN

将 0.4 秒历史按真实时间分为四个互不重叠的时间块。每个块保留原始异步样点及 mask，不先插值成等间隔序列。构造的块输入形状为 `[B, 4, L, F]`；无效位置由 mask 排除。

上游网络用时间感知卷积将每个特征在块内的异步观测编码为 32 维表示，再通过块间 Transformer 和动态特征图传播信息，最后用查询时间解码各特征。这里图节点对应 F 个实数压缩系数分量，不是 64 根物理天线。配置为一个主层、一个 Transformer 层、四头注意力、8 维时间嵌入、10 维节点嵌入及两跳图传播。参考 [t-PatchGNN 官方实现](https://github.com/usail-hkust/t-PatchGNN)。

### Time-RWKV CSI

整个 F 维历史向量先映射到 64 维，与真实时间的正弦/余弦嵌入相加。经过两个 RWKV 风格块，每块包含时间混合、receptance 门控、特征混合与残差连接。记忆权重按实际时间间隔衰减，而非仅按 token 个数衰减。最后有效时刻的状态与查询时间嵌入相加，经 `64 → 64 → F` 读出，再接统一头。

它借鉴 [RWKV 信道预测论文](https://arxiv.org/abs/2606.16170) 的时间混合与衰减思想，但当前深度、宽度、时间处理和查询输出方式都是本任务的适配设计。不能将它的结果直接标注为原文模型性能。

### CT-Transformer CSI

每个复数压缩系数单独形成二维实数序列，各系数共享一个小网络：`[B,L,K,2] → [B×K,L,2] → [B×K,L,16]`。共享处理显著降低参数量，但也限制了骨干中的显式跨系数交互；统一倍率分支仍会读取整体 F 维输出。

细尺度编码器为 16 维、双头、前馈宽度 32 的 Transformer 层。相邻两个观测按有效性平均形成粗尺度表示，再经第二个同规格编码器。两个尺度的记忆拼接后，用查询时间构造 Q/K，通过三点 Gauss–Legendre 求积计算成对线性连续路径的注意力分数。V 分支从各记忆时刻向查询时刻演化，采用四步中点 ODE 更新与轨迹平均；最后逐系数 `16 → 32 → 2` 解码并拼回 F 维。

其设计参考《Continuous-Time Transformer-Based Channel Prediction With Non-Uniform Pilot Pattern》，[作者机构记录](https://eprints.soton.ac.uk/510410/)，DOI `10.1109/TWC.2026.3665056`。本实现采用成对线性路径、简化查询解码器和 PCA 系数，不是原文全局插值、完整编解码器或角域输入的原样实现。上述结构描述以本次本地代码为准。

## 5. 参数量与训练

| 模型 | 前五类单模型参数量 | 遮挡类参数量 |
|---|---:|---:|
| CRU | 101,002 | 323,210 |
| Latent ODE | 239,394 | 543,522 |
| Flow | 285,826 | 622,722 |
| t-PatchGNN | 163,794 | 169,426 |
| Time-RWKV CSI | 113,282 | 146,818 |
| CT-Transformer CSI | 7,572 | 8,084 |

参数量不同，不能把结果解释为严格等容量架构比较。CT 模型参数少主要来自逐系数共享，不代表它只输出少量 CSI 元素。

所有训练使用 seed 17、AdamW、初始学习率 0.001、权重衰减 0.0001、余弦学习率下限 0.00001、梯度范数裁剪 1；最多 60 轮，验证指标连续 12 轮不改善则早停。每轮从该类别训练轨迹重采样 4,000 个窗口，验证固定 600 个窗口。batch 分别为 CRU 256、Latent ODE/Flow/RWKV 128、t-PatchGNN 32（遮挡 16）、CT 16（遮挡 8）。除 CRU 核外使用 BF16 混合精度，并保留输出跳连的 FP32 相加。

目标函数为每个未来目标点的完整矩阵 NMSE：系数误差平方和加上不可恢复的投影残差能量，再除以该目标点完整 CSI 能量；最后对窗口及查询求算术平均。不加入增益辅助损失、显式趋势分支或额外相位增量监督。验证集决定最优 checkpoint，测试集不参与选轮次或调参。各实际早停轮次见 [training.csv](tables/training.csv)。

## 6. 如何理解公平性

同类模型看到相同的数据划分、时间范围和窗口生成规则；测试目标严格配对。但这不是所有网络的充分超参数搜索，也没有做等参数量、等训练 FLOPs 或多种子比较。新旧实验还同时改变了输出头、中心化、归一化和部分潜变量处理，因此新旧提升不能全部归因于“相乘比相加好”。
